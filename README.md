## About

Folia is an online music player centered on immersive full-screen lyrics. It supports NetEase Cloud Music, KuGou, Navidrome, and local libraries, with intelligent lyric matching, AI-generated color themes, and a variety of lyric animations.

Electron desktop releases are available for Windows, macOS, and Linux. The Node.js-based Web version can be deployed to Vercel or other platforms supporting Node.js for browser and mobile use.

## Core features

| Feature | Description |
| --- | --- |
| Online search and playback | Search songs, artists, or albums and play them with automatically loaded artwork and lyrics. |
| Local music | Import local audio and store its index on your device without uploading file contents. See [Local library management](docs/local-library-management.md). |
| Intelligent matching | Automatically match local songs with online lyrics and artwork; manually correct results when needed. |
| Local lyric files | Load same-named `.lrc`, `.vtt`, `.ttml`, `.qrc`, `.yrc`, and `.krc` files alongside audio, or embedded LRC lyrics. Supports enhanced word-by-word lyrics generated by LDDC. |
| Now Playing | Use the local [Now Playing service](https://github.com/Widdit/now-playing-service/) to receive external players' tracks, timelines, and lyrics and drive Folia's stage and full-screen lyrics. |
| AI themes | Generate immersive backgrounds and visual parameters from song mood and lyrics. |
| Cross-platform | Deploy the Web version or install desktop packages. |
| Experimental mods | Extend the desktop app with Folium lyric animations, backgrounds, playback-page layers, and commands. See [Mod system](#mod-system-folium-v1x). |

## Get Folia

Desktop packages bundle frontend and backend runtimes for immediate use.

### One-click deployment

Follow the [Vercel deployment guide](https://folia-site.cielaniska.top/guide/deploy-vercel) to launch the Web version.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/chthollyphile/folia-major)

Cloudflare one-click deployment is also supported; adapt the Vercel instructions as appropriate.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/chthollyphile/folia-major)

For QQ Music on Vercel or Cloudflare, set `VITE_QQ_API_BASE` to `/api/qq` and configure `QQ_SESSION_SECRET` as a server-side secret **without a `VITE_` prefix**. A separate persistent API instance is unnecessary. By default, only WeChat QR login is supported, and login is required before playback. A Cloudflare Durable Object can additionally enable QQ QR login. See [QQ Music deployment](docs/qq-music-deployment.md) for steps, platform differences, and troubleshooting.

For self-hosting, use [Docker Compose](deploy/docker/README.md). Local music directory access requires a trusted HTTPS secure context; the guide covers NAS reverse proxies and certificates.

On mobile, deploy or self-host the Web version and install it as a PWA by adding it to your home screen through Chrome for Android or Safari on iOS. Experienced users can package an Android APK with Capacitor; see [folia-sonnet](https://github.com/chthollyphile/folia-sonnet).

### Downloads

- **Windows / macOS / Linux:** Get the latest installers from [Releases](https://github.com/chthollyphile/folia-major/releases/latest).
- **Arch Linux:** Install [folia-major-bin](https://aur.archlinux.org/packages/folia-major-bin) from AUR.
- **Flatpak:** A third-party community package is available on [Flatpark](https://flatpark.org/apps/top.izuna.foliamajor/).

> [!IMPORTANT]
> If GitHub downloads are slow in mainland China, use [Quark Drive](https://pan.quark.cn/s/6e4c6fa3bc6f) or [Baidu Drive](https://pan.baidu.com/s/1f0x3g-8PMcNCO-TJ5z1rPw?pwd=flia). These mirrors provide stable Windows and Apple silicon installers only.

Linux packages, Wayland / Hyprland remote-control windows, and desktop details are covered in [Technical documentation](docs/technical.md).

## Mod system (Folium v1.x)

> [!NOTE]
> Mods are experimental, desktop-only, and disabled by default. Enable them under Settings → Lab → Mod system.

Folium mods can add lyric animations and backgrounds, overlay playback-page content, add progress-bar buttons and markers, register commands and settings sections, transform lyrics before display, and invoke local tools such as ffmpeg through a Node entry point. Mods run as trusted code: each requires confirmation in a native window before activation and confirmation again after file changes.

- **Marketplace:** [folium-compound.vercel.app](https://folium-compound.vercel.app) provides official and reviewed community mods. Download a ZIP and drag it into the mod panel.
- **Certification:** Marketplace mods carry Folium signatures and appear as certified. Unsigned third-party mods appear as unverified and can still be used.
- **Development:** [Contribution guide](docs/folium/contributing.md) covers authoring, debugging, submission, review, signing, and updates.
- **API:** [API reference](docs/folium/api.md) is generated from contracts and organized by registries, contexts, events, and services.
- **Specification:** [Folium specification](mods/README.md) covers manifests, permissions, registry semantics, events, security, and versioning.
- **Examples:** [`mods/`](mods/) includes lyric animations, parameter controls, progress bars, playback-page layers, and transparent video export.

## Sync Server

The optional official `sync-server` synchronizes appearance settings and AI theme libraries across devices. Users host it themselves.

- **Cloudflare Workers / D1:** Recommended serverless deployment without server administration.
  [![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/chthollyphile/folia-major/tree/main/sync-server)
- **Docker:** See [Docker deployment](deploy/docker/README.md) for images and Compose entry points.
- **Node.js:** Uses SQLite, suitable for local setups or environments where Docker is inconvenient.

Follow the [Sync Server deployment guide](https://folia-site.cielaniska.top/guide/deploy-sync) for environment variables, tokens, and deployment. Enter the server URL and `SYNC_TOKEN` in Folia's storage settings to enable sync.

## Local music and matching

Folia reads audio metadata, lyrics, and artwork from the same directory and supplements information through NetEase Cloud Music, QQ Music, or KuGou, falling back in that order. Inaccurate matches can be corrected by selecting candidates manually, restoring original imported information, or merging and splitting artist and album entities.

See [Local library management](docs/local-library-management.md) for importing, rescanning, matching, entity editing, playlists, caching, and troubleshooting.
